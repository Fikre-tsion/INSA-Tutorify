## 2025-05-15 - Dynamic Content vs. Performance
**Learning:** Transitioning static HTML to client-side JS fetches (CSR) can degrade First Contentful Paint (FCP) and SEO, especially for landing pages.
**Action:** Use server-side rendering (SSR) or static site generation (SSG) for critical above-the-fold content while keeping data dynamic. Alternatively, keep static placeholders or skeleton screens to minimize layout shift.
