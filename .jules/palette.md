## 2025-06-11 - [Backend Integration & Accessibility]
**Learning:** Even when performing a full-stack transformation, maintaining focus on micro-UX (loading states, ARIA labels, focus states) significantly improves the perceived quality and accessibility of the interface. Using `.sr-only` for labels allows for a clean visual design without sacrificing screen reader support.
**Action:** Always include `.sr-only` utility in the project's global CSS and ensure all form inputs have associated labels.
