# 🎓 Tutorify — Smart Tutoring Platform (Frontend)

**Tutorify** is a modern web-based platform designed to connect **students** and **tutors** through an elegant and interactive user interface.  
Built entirely with **HTML, CSS, and JavaScript**, it provides an engaging experience for exploring tutor profiles, managing learning sessions, and navigating a sleek dashboard layout.

---

## 🚀 Features

- 🧑‍🏫 **Tutor Profiles (UI Design)** — Beautiful layout for showcasing tutors and their expertise.  
- 💬 **Chat & Video Call Sections (UI Ready)** — Interactive placeholders for future real-time communication.  
- 🌐 **Language Toggle (English / Amharic)** — Dual-language interface concept for accessibility.  
- ⭐ **Student Rating Section** — Designed for feedback and performance visualization.  
- 🧭 **Responsive Sidebar Navigation** — Smooth hover and click states with animations.  
- 📱 **Mobile-Friendly Design** — Adaptive layout for all screen sizes.  

---

## 🛠️ Tech Stack

- **HTML5** — Structure  
- **CSS3** — Styling and responsive design  
- **JavaScript (Vanilla)** — Interactivity and UI logic  
- **Ionicons & Google Fonts** — Iconography and typography

🎓 Tutorify — Smart Tutoring Platform
💡 Transforming Tutoring Through Technology

Tutorify is a modern web platform that connects students with qualified tutors through a seamless, interactive, and futuristic interface.
It’s designed with a focus on simplicity, transparency, and performance, blending beautiful UI with real functionality.

This is more than a demo — it’s a prototype of an AI-enhanced education platform built with real-world architecture in mind.

🚀 Features Overview
🧑‍🏫 For Students

Browse and connect with verified tutors.

Book tutoring sessions or chat directly.

Rate and review tutor performance.

Access personalized learning recommendations (future feature).

👨‍💼 For Tutors

Register and verify credentials.

Manage student requests and sessions.

Gain reputation through ratings and client feedback.

Upgrade to Pro Level for enhanced visibility.

🛠 Admin Dashboard

Secure login and management tools.

View and manage tutor/student accounts.

Monitor platform activity and performance metrics.

Admin-exclusive dashboard interface.

🔐 Authentication System

A robust dual-role authentication system built from scratch using HTML, CSS, and JavaScript:

🔑 Two login roles: User & Admin

🔒 AES-encrypted password storage in localStorage

💾 JSON-based simulated database

🧭 Session persistence until logout

🎨 Futuristic Tutorify login design

🎨 UI / UX Design

Inspired by futuristic education technology, Tutorify uses:

Sleek neon-glow aesthetic with soft gradients.

Responsive layout for all devices.

Minimalist iconography with Boxicons and Unicons.

Smooth transitions and interactive hover effects.

⚙️ Tech Stack
Layer	Technology
Frontend	HTML5, CSS3, JavaScript (ES6)

Design	Tutorify Custom UI, Boxicons, Google Fonts

Data Handling	LocalStorage + JSON DB

Security	AES Encryption

Version Control	Git & GitHub

(Future Backend)	Node.js, Express.js, MongoDB (Planned Integration)
