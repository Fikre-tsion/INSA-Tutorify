# 🎓 Tutorify — Smart Tutoring Platform

**Tutorify** is a modern full-stack web platform designed to connect **students** and **tutors** through an elegant, interactive, and futuristic user interface.

---

## 🚀 Features

- 🧑‍🏫 **Tutor Profiles & Catalog** — Dynamic course catalog and tutor listings.
- 💬 **Contact & Messages** — Interactive contact form connected to backend API.
- 🔐 **Dual-Role Authentication** — Secure JWT-based registration and login system for Users and Admins.
- 📊 **Admin Dashboard** — Real-time stats, page view tracking, student details, and message management.
- 🧭 **Responsive Navigation** — Smooth navigation menu with dynamic auth state updates.
- 📱 **Mobile-Friendly Design** — Adaptive layout across all screen sizes.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+), Unicons
- **Backend:** Node.js, Express.js, JWT, bcryptjs, CORS
- **Database:** JSON-based persistent storage with asynchronous file queues and in-memory caching

---

## ⚙️ How to Run

1. **Install dependencies:**
   ```bash
   pnpm install
   ```

2. **Start the server:**
   ```bash
   pnpm start
   ```

3. **Run tests:**
   ```bash
   pnpm test
   ```

4. Open `http://localhost:3000` in your web browser.
