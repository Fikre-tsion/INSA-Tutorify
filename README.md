# 🎓 Tutorify — Smart Tutoring Platform

**Tutorify** is a modern, futuristic web platform that connects students with qualified tutors through a seamless, interactive interface. Built with an Express.js backend and a modern HTML5/CSS3/JavaScript frontend, Tutorify includes secure authentication, dynamic course catalogs, interactive contact messaging, and a real-time admin dashboard.

---

## 🚀 Features

- 🧑‍🏫 **Interactive Tutor & Course Catalog** — Dynamic rendering of courses and tutoring subjects.
- 🔐 **Dual-Role Authentication** — JWT-based authentication for Users and Admins.
- 📊 **Admin Dashboard** — Live statistics, message inbox, tutor activity, and customer metrics.
- 💬 **Contact & Messaging System** — Asynchronous contact submissions saved directly to persistent storage.
- 🎨 **Futuristic UI/UX** — Responsive layout, smooth transitions, and high-contrast accessible design.
- 📱 **Mobile-Friendly Layout** — Fully responsive across desktop, tablet, and mobile devices.

---

## ⚙️ Tech Stack

- **Backend:** Node.js, Express.js, JWT (`jsonwebtoken`), `bcryptjs`, CORS
- **Frontend:** HTML5, CSS3, ES6 JavaScript, Swiper.js, Ionicons, Unicons
- **Database:** Local JSON database (`db.json`) with in-memory caching and queued asynchronous persistence.

---

## 🧰 Local Setup & Running

```bash
# Install dependencies
pnpm install

# Start the application server
pnpm start
# Server runs on http://localhost:3000

# Run automated tests
pnpm test
```
