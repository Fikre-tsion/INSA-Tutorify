# 🎓 Tutorify — Smart Tutoring Platform

**Tutorify** is a modern, high-performance web platform that connects **students** and **tutors** through a seamless and interactive interface.

---

## 🚀 Features

- 🧑‍🏫 **Tutor Profiles & Catalog** — Showcase tutors, courses, and educational expertise.
- 🔐 **Dual-Role Authentication** — Secure User & Admin authentication with JWT and bcrypt password hashing.
- ⚡ **High-Performance Express Backend** — Non-blocking asynchronous I/O and in-memory caching for low-latency requests.
- 📊 **Admin Dashboard** — Real-time metrics and account management interface.
- 📱 **Responsive Design** — Mobile-friendly navigation and smooth transitions across all devices.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), Swiper.js, Unicons, Ionicons
- **Backend**: Node.js, Express.js
- **Authentication & Security**: JSON Web Tokens (JWT), bcryptjs
- **Data Persistence**: Asynchronous JSON database with in-memory read cache

---

## ⚙️ How to Run

```bash
# Install dependencies
pnpm install

# Start the Node.js server
pnpm start
```

Navigate to `http://localhost:3000` in your web browser.
