# 🎓 Tutorify — Smart Tutoring Platform

**Tutorify** is a modern web-based platform designed to connect **students** and **tutors** through an elegant and interactive user interface.
It blends a futuristic UI with real-world architecture, providing an engaging experience for exploring tutor profiles, managing learning sessions, and navigating a sleek dashboard.

---

## 🚀 Features

### 🧑‍🏫 For Students
- **Tutor Profiles** — Beautiful layout for showcasing tutors and their expertise.
- **Interactive Learning** — Discover step-by-step tutorials and expert guidance.
- **Student Rating Section** — Feedback and performance visualization for tutors.
- **Course Exploration** — Browse and enroll in various educational categories.

### 👨‍💼 For Tutors
- **Profile Management** — Register and showcase credentials.
- **Session Management** — Placeholder for future real-time communication tools.

### 🛠 Admin Dashboard
- **Role-Based Access** — Secure login and management tools for admins.
- **Platform Analytics** — Monitor activity and performance metrics.
- **Responsive Sidebar Navigation** — Smooth hover and click states with animations.

---

## 🔐 Authentication System
A robust dual-role authentication system built with a focus on security and persistence:
- **Two Roles**: User & Admin.
- **Secure Storage**: JWT-based authentication with local persistence.
- **Dynamic UI**: Navigation updates based on authentication state.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Backend**: Node.js, Express.js
- **Database**: JSON-based persistent storage
- **Design**: Boxicons, Unicons, Swiper.js, Google Fonts

---

## ⚙️ How to Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Fikre-tsion/Tutorify.git
   cd Tutorify
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   ```

3. **Start the server**:
   ```bash
   pnpm start
   ```

4. **Access the application**:
   Open `http://localhost:3000` in your browser.
