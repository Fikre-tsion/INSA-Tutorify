# 🎓 Tutorify — Smart Tutoring Platform

**Tutorify** is a modern web platform that connects students with qualified tutors through a seamless, interactive, and futuristic interface. Built with performance, simplicity, and accessibility in mind.

---

## 🚀 Features

- 🧑‍🏫 **Tutor Profiles & Search** — Explore tutor profiles and expertise.
- 🔐 **Authentication System** — Node.js & JWT-based dual-role login (User & Admin).
- 🛠 **Admin Dashboard** — Account management and platform metric monitoring.
- 📱 **Responsive Design** — Adaptive layout for all screen sizes with accessible interactions.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Backend:** Node.js, Express, JWT, bcryptjs
- **Database:** JSON file-based database (`db.json`)

---

## ⚙️ How to Run

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Start the backend server:
   ```bash
   pnpm start
   ```
3. Open `http://localhost:3000` in your browser.
