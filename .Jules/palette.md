## 2026-05-12 - Form Navigation Accessibility & Async Feedback in Auth Views
**Learning:** Custom interactive elements (like `.toggle` divs used to switch between login and registration forms) are inaccessible to screen reader and keyboard users unless given explicit `tabindex="0"`, `role="button"`, and keydown listeners for Space/Enter keys. Additionally, form controls without explicit labels or `aria-label` attributes leave screen reader users without context. Providing instant button disabled and text feedback during async requests prevents duplicate submissions while reassuring users.
**Action:** Always add explicit `aria-label` or `<label>` elements to form controls, make non-button interactive elements keyboard navigable with `tabindex="0"` and keydown handlers, and toggle disabled loading state indicators on async submit buttons.
